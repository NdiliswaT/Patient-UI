A lightweight web-based Patient interface built using HTML, CSS, and Vanilla JavaScript, integrated with Google Firestore REST API for real-time data retrieval and patient creation.

📌 Features

✔️ Fetch and display patient records from Firestore
✔️ Search patients dynamically by name or surname
✔️ Add new patients via a Firestore POST request
✔️ Responsive UI optimized for desktop and mobile
✔️ Clean, modern interface for easy data reading
✔️ No backend server required — runs fully client-side

🖼️ UI Overview

Displays all patients in a card-style layout using a 3-column responsive grid

Includes search input for instant filtering

Add Patient form captures:

Name

Surname

Address

Email

Phone

Data automatically refreshes after adding a patient.

🛠️ Tech Stack
Area	Technology
Frontend	HTML + CSS + JavaScript
Database	Google Firestore REST API
Deployment	Any static hosting (GitHub Pages, Netlify, Firebase Hosting, etc.)
