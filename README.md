# Patient UI
AI Clinical Notes Summary Tool

## Overview
A Flask-based web interface that processes patient clinical histories and uses an AI model to generate concise summaries of each clinical encounter. Designed to help clinicians and administrative staff quickly review patient timelines and extract the main takeaways without manually reading long files.

## Features
- Upload or read patient history files to generate summaries.
- Structured display of clinical encounter summaries with dates.
- Fetches authentication tokens to interact with APIs securely.
- Modular and extendable Flask architecture.

## Tech Stack
- Backend: Python, Flask
- Frontend: HTML5, CSS3, JavaScript
- AI Integration: Ollama or other LLM endpoints
- Dev Tools: Git & GitHub
